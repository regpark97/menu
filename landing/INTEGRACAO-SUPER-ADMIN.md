Este kit adiciona ao seu projeto `menu` (regpark97/menu):

1. Tabela `leads` no Supabase
2. Aba "Leads" no painel Super Admin
3. Integração do formulário da LP com o backend

## 1. SQL — criar tabela `leads` no Supabase

Rode no SQL Editor do Supabase (mesmo lugar onde rodou as migrations do drizzle):

```sql
-- Tabela de leads vindos da landing page
create table if not exists leads (
  id            bigint generated by default as identity primary key,
  establishment text not null,
  owner         text not null,
  phone         text not null,
  email         text not null,
  segment       text not null,
  status        text not null default 'new',  -- 'new' | 'contacted' | 'demo' | 'closed'
  created_at    timestamptz not null default now()
);

-- RLS: super admin lê tudo; inserção é pública (formulário da LP usa anon key)
alter table leads enable row level security;

-- Qualquer um insere lead (o formulário é público)
create policy "leads_insert_public"
  on leads for insert
  to anon, authenticated
  with check (true);

-- Leitura: apenas super admin (ajuste a função conforme seu schema real,
-- ex.: is_super_admin() ou a verificação que você usa em tenants)
create policy "leads_read_super_admin"
  on leads for select
  to authenticated
  using (
    exists (
      select 1 from tenants t
      where t.owner_user_id = auth.uid()
        and t.slug = 'admin'  -- ← troque pela sua lógica real de super admin
    )
  );

-- Atualizar status do lead (também só super admin)
create policy "leads_update_super_admin"
  on leads for update
  to authenticated
  using (
    exists (
      select 1 from tenants t
      where t.owner_user_id = auth.uid()
        and t.slug = 'admin'  -- ← troque pela sua lógica real de super admin
    )
  );

-- Índice para listar ordenado por data
create index if not exists leads_created_at_idx on leads (created_at desc);
```

> ⚠️ **Ajuste a política de leitura:** troque o trecho `t.slug = 'admin'` pela lógica que seu projeto realmente usa para identificar o super admin (vi no seu HANDOFF/README que existe autenticação e níveis — adapte para `is_super_admin()` ou como for).
>
> ⚠️ **Segurança extra recomendada:** o insert público sem limites pode sofrer spam. Duas opções simples:
> - Adicionar um "honey pot" no formulário (campo escondido que bots preenchem) — já incluído no JS da LP via validação
> - Ou usar um limite de rate no edge function/Supabase se notar abuso

## 2. Código da aba "Leads" no Super Admin

Adicione ao `src/components/dashboard/sections.ts`:

```ts
export const sections = [
  // ... suas seções existentes ...
  { id: 'leads', label: 'Leads da LP', icon: 'Users' }
];
```

Crie o arquivo `src/components/dashboard/LeadsSection.tsx`:

```tsx
import { useEffect, useState } from 'react';
import { supabase } from '@/integrations/supabase/client';

type Lead = {
  id: number;
  establishment: string;
  owner: string;
  phone: string;
  email: string;
  segment: string;
  status: string;
  created_at: string;
};

const SEGMENT_LABELS: Record<string, string> = {
  cafe: 'Cafeteria', restaurante: 'Restaurante', bar: 'Bar / Boteco',
  hamburgueria: 'Hamburgueria', pizzaria: 'Pizzaria', doceria: 'Doceria',
  sorveteria: 'Sorveteria', foodtruck: 'Food truck', outro: 'Outro',
};

const STATUS_FLOW = ['new', 'contacted', 'demo', 'closed'];
const STATUS_LABELS: Record<string, string> = {
  new: 'Novo', contacted: 'Contatado', demo: 'Demo agendada', closed: 'Fechado',
};

export function LeadsSection() {
  const [leads, setLeads] = useState<Lead[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    supabase
      .from('leads')
      .select('*')
      .order('created_at', { ascending: false })
      .then(({ data }) => { setLeads(data ?? []); setLoading(false); });
  }, []);

  async function updateStatus(id: number, status: string) {
    setLeads(ls => ls.map(l => (l.id === id ? { ...l, status } : l)));
    await supabase.from('leads').update({ status }).eq('id', id);
  }

  if (loading) return <p className="text-sm text-muted">Carregando leads…</p>;

  const newCount = leads.filter(l => l.status === 'new').length;

  return (
    <div className="space-y-6">
      <div>
        <h2 className="text-2xl font-semibold">Leads da landing page</h2>
        <p className="text-sm text-muted-foreground">
          {leads.length} leads no total · {newCount} aguardando contato
        </p>
      </div>

      {leads.length === 0 ? (
        <p className="text-sm text-muted-foreground">
          Nenhum lead ainda. Assim que alguém enviar o formulário da LP, aparece aqui.
        </p>
      ) : (
        <div className="rounded-xl border overflow-hidden">
          <table className="w-full text-sm">
            <thead className="bg-muted/50">
              <tr>
                <th className="p-3 text-left">Estabelecimento</th>
                <th className="p-3 text-left">Proprietário</th>
                <th className="p-3 text-left">Contato</th>
              </tr>
            </thead>
            <tbody>
              {leads.map(lead => (
                <tr key={lead.id} className="border-t">
                  <td className="p-3">
                    <div className="font-medium">{lead.establishment}</div>
                    <div className="text-xs text-muted-foreground">
                      {SEGMENT_LABELS[lead.segment] ?? lead.segment}
                    </div>
                  </td>
                  <td className="p-3">
                    <div>{lead.owner}</div>
                    <div className="text-xs text-muted-foreground">
                      {new Date(lead.created_at).toLocaleString('pt-BR')}
                    </div>
                  </td>
                  <td className="p-3">
                    <div className="flex flex-col gap-1">
                      <a className="text-blue-600 hover:underline" href={`mailto:${lead.email}`}>
                        {lead.email}
                      </a>
                      <a
                        className="text-green-600 hover:underline"
                        href={`https://wa.me/55${lead.phone.replace(/\D/g, '')}`}
                        target="_blank" rel="noreferrer"
                      >
                        {lead.phone}
                      </a>
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      )}
    </div>
  );
}
```

## 3. Integrar o formulário da LP com o Supabase

Na LP (`bupin-lp/index.html`), dentro do handler `submit`, troque o bloco "Modo demonstração" pelo fetch real:

```js
const SUPABASE_URL = 'https://SEU-PROJETO.supabase.co';
const ANON_KEY = 'SUA_ANON_KEY';

const res = await fetch(`${SUPABASE_URL}/rest/v1/leads`, {
  method: 'POST',
  headers: {
    'apikey': ANON_KEY,
    'Authorization': `Bearer ${ANON_KEY`,
    'Content-Type': 'application/json',
    'Prefer': 'return=minimal'
  },
  body: JSON.stringify({
    establishment: payload.establishment,
    owner: payload.owner,
    phone: payload.phone,
    email: payload.email,
    segment: payload.segment
  })
});
if (!res.ok) throw new Error('Falha no envio');
```

Encontre `SUPABASE_URL` e `ANON_KEY` no painel do Supabase → Settings → API. O mesmo `client.ts` do projeto `menu` já usa esses valores.

## 4. Subir a LP pra dentro do repo (para retomar depois)

Como o repo já tem a Vercel configurada, o ideal é copiar a pasta `bupin-lp/` para dentro do projeto `menu/`:

```
menu/
  bupin-lp/        ← copie a pasta inteira
    index.html
    images/
      hero.jpg, focaccia.jpg, ...
  src/
  public/
  ...
```

Depois, se quiser servir a LP como rota do próprio app (ex.: `menu.com/lp`), basta criar um roteamento estático no `vite.config.ts` (posso ajudar quando for a hora). Ou simplesmente hospedar a pasta `bupin-lp/` de forma independente (Netlify, Vercel estático, GitHub Pages).
